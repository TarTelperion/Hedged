# Hedged

Hedged is a personal budget for Android built with Kotlin, Jetpack Compose, Material 3, Room, and SQLite.

## What it includes

- Fast native income and expense entry
- Custom income and spending categories
- Fixed or percentage-of-income monthly budgets
- Monthly income, spending, allocation, and net-cash-flow summaries
- Savings goals with contributions and withdrawals
- Transaction history
- App-owned JSON backup and restore

## Build

Open the project in Android Studio and run the `app` configuration, or use:

```text
./gradlew assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

Minimum Android version: Android 8.0 (API 26).
